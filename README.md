#Python BMI Calculator

-A simple, commandline Body Mass Index(BMI) built in Python as my first project of my journey learning Python.

-Features
- Dynamic Input: Prompts the user to enter their height and weight in metric units.
  
- Auto Calculation: Uses the standard math formula of BMI with presicion rounding.
  
- Health Catergorization: Takes the standard weight categorys and tells the user their corresponding category (Overweight for example)

-Technology used

- Python 3
  
- Visual Studio Code
